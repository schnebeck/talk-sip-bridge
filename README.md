# FritzBox Talk Bridge

Production-track successor to the `sip-fritzbox-experiment` proof of concept:
connects a FritzBox phone line to Nextcloud Talk using Talk's native SIP
bridge protocol (the "internal client" `dialout`/virtual-session mechanism),
instead of a custom chat-bot UI.

See `docs/CONCEPT.md` for the architecture and what carries over from the PoC.

## Status

Not yet implemented. This repository currently holds only the initial
structure and the migration concept.
